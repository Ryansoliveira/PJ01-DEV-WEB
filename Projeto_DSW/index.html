Projeto DSM - Disciplina de Desenvolvimento Web 3 - Webserver em Node.js

Apresentação do Projeto

Este projeto consiste em um servidor web desenvolvido em Node.js (sem a utilização de frameworks como o Express) para a disciplina de Desenvolvimento de Software Multiplataforma (DSM) da Fatec. O objetivo principal é explorar o funcionamento de rotas, manipulação de arquivos estáticos (HTML, PDF e imagens) e respostas HTTP nativas do Node.js.

Instruções de Navegação

Para navegar pelo sistema, utilize os botões abaixo:

  • Clique no botão referente ao integrante desejado para visualizar sua página "Sobre".
  • Dentro de cada página individual, você encontrará as informações do integrante, o acesso ao seu Currículo (PDF) e um botão para retornar a esta tela inicial.
