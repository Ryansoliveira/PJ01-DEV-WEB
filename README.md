# Portfolio Dupla — Desenvolvimento Web III
Aplicação web desenvolvida como o Projeto 01 da disciplina de Desenvolvimento Web III. O objetivo principal do projeto é apresentar o perfil profissional e o currículo dos dois integrantes da dupla através de um servidor Node.js com rotas organizadas, além de disponibilizar a documentação completa do projeto.



# 🚀 Funcionalidades e Rotas
A aplicação é organizada através de rotas dinâmicas e estáticas no Express/Node.js, atendendo aos seguintes caminhos:

Página Principal (/): Exibe o index.html com o nome dos integrantes, apresentação geral, instruções de navegação e links direcionando para o perfil de cada um.

Rotas Individuais (/Ryan e /Eduardo):

/sobre: Apresentação pessoal e história de cada aluno.

/currículo: Visualização e download do currículo individual em formato PDF.

Rota do Projeto (/projeto): Acesso à documentação completa do projeto em PDF contendo o objetivo, a estrutura do código-fonte e as considerações finais.



# 🛠️ Tecnologias Utilizadas
Node.js: Ambiente de execução JavaScript no backend.

Express.js: Framework para gerenciamento de rotas e arquivos estáticos.

HTML5 & CSS3: Estrutura e estilização das páginas web.

PDF: Formato utilizado para exibição dos currículos e documentação técnica.
